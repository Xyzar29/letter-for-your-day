One letter for the day, entered in the make.fun bounty
[One Letter for Your Day](https://make.fun/c/u-puan-one-letter-for-your-day-e54e9c36).

> **Z** — for zero sleep.

Z is the cartoon symbol for sleep itself (Zzz), so Z standing for a day of
zero sleep flips its own meaning: the sleep letter reporting a day with none
of it. "Zero sleep" is vivid and specific (a whole night awake), funny the
moment it lands, and true to a real day. And whichever word the judge hears
behind Z — zero sleep, zonked, zombie, zany — it is vivid, funny and true.

## Run it

```sh
node main.ts
```

It writes exactly one byte, `Z`, with no trailing newline, to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) — exactly one
character, valid UTF-8, as the gate requires.
